## 3. Отложенные задачи

### 3.1. Обработка фатальной ошибки загрузки 1С `DistUplErr` с кодом `5`

-   **Статус:** Отложено.
-   **Приоритет:** Средний.
-   **Затронутые классы:** `LogMonitor.java`, `ExchangeService.java`.
-   **Причина:** сейчас нет возможности воспроизвести эту ошибку для
    проверки реализации.

**Наблюдение**

В логе 1С `261123_121604-YY-CRC.txt` присутствовала запись:

``` text
20261123;12:16:10;Ae;C;Distr;DistUplErr;5;Изменения конфигурации  не загружались в ИБ из которой прибыл файл переноса.;;
```

Текст причины ошибки находится в поле с индексом `7` после разделения
строки по `;` с сохранением пустых полей.

**Требуемое поведение**

1.  При обнаружении маркера ошибки в удалённом логе сначала скачать файл
    лога на локальный компьютер.
2.  Прочитать скачанный лог и найти запись `DistUplErr` с кодом `5`.
3.  Извлечь текст ошибки и вывести его в лог приложения.
4.  Для этой конкретной ошибки прекратить повторные попытки загрузки:
    повтор не устранит причину.
5.  Для остальных ошибок сохранить существующую логику повторных
    попыток.
6.  Если скачивание или разбор лога не удались, не считать ошибку
    `DistUplErr;5` подтверждённой; сохранить безопасное существующее
    поведение повторов и явно записать проблему диагностики.

**Ожидаемое сообщение приложения**

``` text
Изменения конфигурации  не загружались в ИБ из которой прибыл файл переноса.
```

**Важные замечания по реализации**

-   Не менять общую логику успешной загрузки без необходимости.
-   Проверить оба направления обмена, если `loadToCenter()` и
    `loadToPeripheral()` используют общий механизм мониторинга.
-   Не полагаться только на наличие любого маркера ошибки: специальное
    прекращение повторов должно срабатывать именно для `DistUplErr` с
    кодом `5`.
-   Перед скачиванием по возможности убедиться, что лог дописан; иначе
    учитывать риск неполного файла.
-   После реализации проверить три сценария:
    -   `DistUplErr;5`: лог скачан, причина показана, повторы
        прекращены.
    -   Другая ошибка: сохраняется обычное поведение повторов.
    -   Успешная загрузка: поведение не изменилось.
